# Papyrus Privacy Policy

**Effective date:** 19 November 2026

Papyrus does not collect any user data.

- **No network access.** The app declares no network permission, so it cannot send anything off the device.
- **No ads, accounts or analytics.** There is no sign-in, no advertising SDK and no analytics SDK.
- **Local crash logs.** A crash is written as an ACRA JSON file in app storage and nothing is transmitted. Document
  paths, content URIs and storage locations are redacted before the report is saved. Delete a report in
  **Settings -> Crash Reports**.

To search inside your documents, Papyrus keeps their text in its private database on your device. That text never
leaves the device, is removed with the document, and is not kept for password-protected documents. Very large files are
not read for search, and a long document is indexed only up to a limit.

Highlights, notes, bookmarks and reading positions are kept in the same private database, removed with the document,
and never leave the device.
