# Settings

Labels match the app; defaults are the app's own.

- **Theme**: system, light or dark; applied before the first frame.
- **Colorblind mode**: blue/orange/teal palette.
- **Night mode**: invert PDF pages and slide bitmaps.
- **Syntax highlighting**: comments, strings, keywords and numbers in source/config files.
- **Line numbers**: gutter in text, logs and code.
- **Wrap long lines**: wrap at screen edge; off scrolls sideways.
- **Hyphenation**: syllables in `.txt` only; never logs or code.
- **Pretty print structured files**: indent JSON, XML, HTML and SVG at the chosen **Tab size** (2, 3, 4 or 8 spaces);
  the stored file is unchanged and oversized files open as stored.
- **Autosave external docs**: add another app's document to the library; off uses the viewer's **Save to library**.
- **Autosave encrypted docs**: same for protected PDF/Word/OpenDocument/PPTX; never stores the password.
- **Remember reading position**: reopen at the saved position and show Home progress; stored values return if switched
  back on.
- **Search inside documents**: background text index; small files are immediate, larger files pause while reading or
  under battery saver; off stops new indexing but keeps existing matches ([ARCHITECTURE.md](ARCHITECTURE.md#content-search)).
- **Crash Reports**: list, open read-only or delete local ACRA JSON reports.
- **About**: version, release notes, source, Apache 2.0 license, privacy policy.
